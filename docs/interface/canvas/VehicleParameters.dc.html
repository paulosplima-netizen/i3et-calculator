Vehicle parameters

Specified in docs/01-especificacao-funcional.md, §7.2

Exogenous values describe the vehicle and are yours to set. Endogenous ones are computed from them — shown here in grey, with the equation beside each. A value you supply is never undone by the equation that would have produced it; the IsCalculated column records which is which.

This is a reference vehicle: its parameters are read-only. Create a copy on the Vehicles screen to change anything.
